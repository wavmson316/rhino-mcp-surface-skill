# 重复单元、孔口与极轴阵列

只在确认几何确实重复时建一个母单元再阵列；记录轴、数量、相位、旋转方向和局部变化。非均匀叶片/渐变格栅不能机械复制为完全相同。阵列前检查母单元和旋转后邻居的接界、重叠、间隙、方向及主剪影。

孔可由母面修剪、带孔平面、内壁与封边、局部分面或适合的布尔构造表达。孔具有造型侧壁时先控制其倾角与过渡；不能声称布尔孔必定直上直下，也不能把所有孔都拆成径向面带。选保留设计约束且稳定的表示。

控制点曲线适合公平性编辑，穿点插值适合真实点约束；二者都有可能过冲或偏离目标。解析直线/圆弧优先保留。控制点包络不是实面尺寸，实际测曲线/曲面。不同控制点数的截面仍可 Loft，关键是参数与特征对应、方向和闭合缝；相同点数并不保证无扭转。

棱线按真实设计保留；窄 Blend/Fillet 可以正确表达软锐转折，宽度/半径来自任务。不要普遍禁止圆角，也不把“窄带”作为所有对象的目标。曲率符号检查仅对已知应凸的平面轮廓区域有效，符号依赖方向和参考法向；凹轮廓允许变号。

固定相机与配准比较主轮廓、孔和局部特征，不通过单独缩放/移动每个候选来提高 IoU。纯色无阴影剪影更易分割；渲染材质高光与阴影可能污染阈值，不能视为可靠真值。

## 本次核验的 API

Rhino 8.29：`Brep.CreatePlanarBreps([outer, inner], tolerance)` 能正确建立带孔平面；本次外 40×40、内 10×10 得到 2 个环、面积 1500。`Extrusion.AddInnerProfile` 是另一种带孔挤出方案，需核对同平面、闭合、嵌套关系、返回状态及实体结果。不要因一次传参错误否定整个 API。

保存母单元原始曲线、轴与阵列参数至 `lines` 和项目记录。按任务决定保留实例或独立副本；变换后复核接界。具体轮毂的尺寸、采样数和 IoU 不构成本技能对其他物体的验证。
