# 推理示例与迁移基准

下面是任务模板，不声称已对真实参考做端到端重建。参数由项目输入决定。

## 圆润音箱：先判断几何，不按品类选G级

观察顶底截面、最大腹部、前后对称与网罩边界。A方案若绕轴对称，用Revolve主壳，接缝放低敏感区；B方案若前后非对称，用若干横截面Loft或前后主面+侧带。无尺度先归一化高度，先相机与体块再细节。验收剪影、腹部高度、顶底收束、开口与反射，背面接口未知时标设计补全。

## 高光鼠标与拇指深凹

关键为顶部拱高、尾部收束和凹区深度。A：顶面/侧面/凹底各自控制，宽过渡带和前后角区；B：一张多跨母面雕塑。浅凹可先试B；深凹牵扯顶面时优先A。用穿最深点的纵横截面控制，不描黑影当凹边。角区捏尖先扩大范围和调切线；未可靠测G2就只报目标。

## 三向管柄

尺寸基准是各分支轴与截面。A解析分支+桥接+中心四边区；B扩大中心网络重构；C概念SubD。试中心截面和过渡宽度，三张桥接各自G2不等于中心整体G2。若制造管件另测壁厚、通道和自交。

## 路由器或空调：两种有效形体

参考明确箱体时用平面/挤出加合适圆角；参考有双曲率鼓面时用截面母面或Sweep，按高光需要选择G1/G2。没有“该品类只能平面”。天线/导风板按运动件独立，孔阵列先验证一个单元、边缘余量和局部壁厚，再复制；是否等距由设计决定。

## 汽车面板与分缝

先主剪影和轮拱/肩线体量，比较跨零件母面与局部分块。母形顺后切分零件，分开设缝宽、翻边与厚度；大/小圆角按角区依赖选序。Pipe切带后Blend/Sweep是候选，固定半径要求用适合的圆角构造。风挡由真实曲率决定。

## 扫描工具握柄

先定标与轴线、识别圆柱接口和握持非对称，区分扫描噪声与真实凹纹。按主截面拟合母面，接口保持解析；握持区布局可比较多跨大面与分区过渡。报告偏差分布及功能基准，别用全局均方值掩盖接口超差。

## 反例驱动的Agent评估

| 输入/约束 | 期待行为 | 失败 |
|---|---|---|
| 无尺寸单图 | 可修改归一化、相机/背面假设 | 编毫米精度或停工索图 |
| 视图比例矛盾 | 找公共锚点、记录冲突 | 随意拉伸后称精确 |
| 同边两面折90° | G0候选、拒绝G1 | 看边曲率报G2 |
| 两开放曲线端点90° | 正确拒绝曲线G1 | Unitize布尔值当点积 |
| 平面与相切圆柱 | G1与G2分开 | 法线一致即G2 |
| 重复节点曲线 | 读真实跨度 | CP−Degree |
| 双曲率玻璃/高光家电 | 根据参考构面 | 按产品标签压成平面 |
| 五边孔 | 先检查母面trim可否表达 | 为凑四边切碎主面 |
| 可展板材要求 | 验应变/可展性 | 双曲面直接承诺无应变展开 |
| 仅开放曲面交付 | 按合同报告裸边 | 强行封底改形 |

端到端基准应至少含单图有机壳、带尺寸解析+自由曲面、复杂交汇三类，保存参考、参数、结果与四类验收。自动脚本测试不能替代这些基准。
