# 输入、意图与不确定性

## 先定义要还原的内容

用3–5个有辨识力特征描述目标：长宽高比例、最大腹部/拱高、肩线/凹陷、负空间、边缘软硬、分件与活动关系。记录用途、参考可信度和允许补全。用户设计要求与照片不一致时，把“忠实复原”和“再设计”分开，不能私自美化。

| 输入 | 可支持的约束 | 主要风险 |
|---|---|---|
| 带尺寸正交图 | 尺度、投影轮廓、装配位置 | 图纸畸变、视图不同版本 |
| 透视照片 | 投影轮廓、遮挡、反射趋势 | 焦距/深度耦合、畸变 |
| 草图/文字 | 风格、关键比例、造型方向 | 透视可不一致、背面未知 |
| 网格/点云 | 采样位置和偏差统计 | 噪声、离群、孔洞、扫描配准 |

优先级通常为明确尺寸/装配→用户强调特征→可靠多视图→截面与反射→细节；存在矛盾先记录并按来源取舍，不悄悄平均。

## 线条判读

外轮廓可能是视点相关的遮挡轮廓，不能直接当固定三维边。亮带可能是圆角也可能是反射光源；黑区可能是孔、凹坑或材质。明暗交界是形体线索，不自动要求分面或降低连续性。将每项标为观察/多视角核实/推断/未知。

## 正交图定标

明确世界轴与图片平面：例如X长、Y宽、Z高；记录图像y向下和左右手性。已知长度L对应像素距离d，则 `s=L/d`。对图片平面单位基向量A、B及原点O：

```text
a = s * (px - px0)
b = s * (py0 - py)
P = O + a*A + b*B
```

再用独立尺寸或公共锚点检查缩放、翻转和裁切偏移。图纸确有非等比畸变才校正，记录变换和残差。两点不能任意推导两个独立轴的比例。

无尺度先令总长为1或1000归一化单位；用户补尺寸后整体缩放，再检查厚度/间隙是否也应缩放。照片不确定度与几何接缝公差分开。

## 透视参考

先低复杂度体块匹配投影类型、朝向、位置、焦距与裁切。固定相机后比较形体；每轮只改变有解释的参数。单图不确定深度时保留合理候选，不假装唯一解。平面单应只矫正该平面，不能把整幅三维照片统一px转mm。

## 误差与指标

正交定位误差e像素、比例s时，位置不确定度约e*s，另计线宽、配准和扫描误差。照片优先报告像素/归一化残差及相机条件。

可比较关键点、轮廓距离、截面、IoU、扫描距离分布。IoU只反映面积重叠，不能验证深度、小孔、曲率或尺寸。固定投影/画幅/裁切；指标需写算法和采样分辨率。无图像查看能力时明确只做了几何/数值核对，不称目视通过。
