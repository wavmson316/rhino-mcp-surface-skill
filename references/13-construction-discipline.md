# 施工依赖与回退纪律

先读 [构面决策](15-surface-led-construction.md)。施工顺序由依赖关系决定，不使用“不可逆三铁律”代替分析。

- 记录单位、公差和尺度来源；无尺寸可建立归一化模型并明示假设。规划与试面交替，不要求进软件前完成全部分面。
- 保留未修剪母面与阶段版本。主形→派生细节是常见依赖；开槽、圆角、分缝的具体次序按相交关系和保留面决定，必要时比较顺序或显式构造过渡。
- 先大后小圆角只是常用候选。不同零件可以独立施工，但必须共享装配基准与间隙约束；非对称不意味着所有零件必须同步完成。
- 自然边附近前几排 CV 与导数的关系有夹持、节点、权重、非退化等前提；不能宣称“其余点任意动”。修剪边需另查。
- EdgeSrf 不要求四边次数相同。精确兼容化不自动改变输入几何，但仍须检查内部形状。Blend 的 Same height shapes 不是通用修复开关。
- 小面同样可用 Zebra/EMap，效果受显示精度、比例、视角和映射影响；与截面及数值检测交叉检查。CurvatureAnalysis 不是形状正确或 G2 的单项证明。
- 开放外观面和汽车覆盖件可按交付合同交付；水密要求由实体/制造任务决定。
- 保护已有文档。只操作已记录 ID，失败先查状态，超时不盲目重放。

每阶段记录形体、连续性、结构、工程四类验证和未测项；不要用命令成功、整齐点数或测试脚本通过冒充复杂物体还原成功。
