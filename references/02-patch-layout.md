# 分面、UV流向与邻接

## 三种结构分开

NURBS底层面为参数矩形S(u,v)；trim环限定可见区域，Brep边/二维trim描述边界拓扑。显示等参线不等于节点/跨度；Mesh或SubD四边拓扑也不等于NURBS控制网。五边孔可以只是四边母面上的修剪。

## 规划步骤

1. 识别主轴、主要纵横截面、隆起/鞍形/凹区、真实折棱与对称面。
2. 让一族UV顺随主要形流，另一族控制截面；长条通常沿长度走一向，但没有“U必须沿长边”。
3. 把四侧边配成几何相容的两对，检查端点、切线、参数分布与角点夹角；参数速度差会导致聚线和扭转。
4. 将大形主面、过渡带、角区与局部特征分配不同职责。反射敏感区给过渡足够宽度，避免细长碎面和无理由极点。
5. 用少量试面比较方案，再更新邻接表。分面是可迭代设计，保留母面降低回退成本。

**值得分面：**真实折棱、多方向分叉、流向转折、边界约束冲突、局部复杂度需要隔离。
**未必需要分：**材质、阴影、可在良好母面上修剪的孔、零件缝、追求全单跨。

## 每块面和每条接缝的合同

| 面块字段 | 内容 |
|---|---|
| P01范围与角色 | 主面/侧面/过渡/补角 |
| U/V | 两族流向及方向说明 |
| 四侧边 | 自然、修剪、闭合接缝、退化边 |
| 依赖 | 输入曲线/父母面、固定对象 |
| 调整预算 | 可动边、可变宽度、允许偏差 |
| 目标与风险 | 各边G级、极点、窄带、角兼容 |

每条E01记录两侧具体面/边、连续性或有意开缝、允许偏差、端点兼容、检查方法与状态。拓扑编辑后edge索引可能重排，凭几何位置/父对象重新识别，不能复用失效索引。

## 依赖顺序

整体体块和装配基准→主母面→从属面→过渡带→角区→相关细节。非对称产品各大块先共同定比例，再分件细化；不是禁止独立零件建模。

圆角/槽顺序由特征相交决定。先大后小、先切槽后圆滑都是可试策略；必要时局部重做。顺序并非不可逆，前提是保存几何版本与输入。

## 角区与奇点

两条边在角点的切线和横向导数必须兼容。多面交汇逐边Match并不保证角点同时成立；可改边界、扩大过渡、改变汇聚位置/连接数量。球极点与锥顶可合理存在，但避免在关键均匀高光区随意设置坍缩边。

五边区先比较：恢复更大母面再trim；拆成多个四边区；调整周边布局。不是每条边都必须G2，有意锐边可G0。反复失败应回到邻面约束。
