# 从物品到可施工面块：详细建模剧本

本篇是“参考怎样变成模型”的施工层。复杂物品建模前必读；需要与 [输入分析](01-intent-and-reference.md)、[分面原则](02-patch-layout.md) 配合。下列鼠标、音箱等是**可调整模板**，不能不看用户参考就原样复制。

## 0. Agent在造面前必须产出的五项内容

1. **形体句子**：用几何描述物品，例如“前低后高的双曲率上盖，左侧有深凹握持区，底沿近似平面”，不要只说“流线型鼠标”。
2. **约束表**：整体长宽高、最大体量/高点位置、主要轮廓与负空间、对称/非对称、零件及运动关系；每项标明确尺寸/参考观察/假设。
3. **曲线图谱**：每条线的ID、来源视图/截面平面、起止点、角色及谁可以修改。三维轮廓先在多个可靠视图核对。
4. **面块与邻接表**：每面四侧来自哪些边/截面；U/V、构面输入、相邻G级、可移动范围。识别补角和奇点，不等做到最后再随便Patch。
5. **施工顺序与停止条件**：哪些母面先固定，哪些细节后派生；每阶段如何与参考比较，不通过时回哪一级。

规划允许试面后修改，但不能把“按几何选命令”当成完整施工计划。没有画图工具时使用文字方位、曲线ID和邻接表，不假称已绘图。

### 记录格式：示例而非强制数值

```text
P01 顶部母面
范围：前后装配切平面之间的可见顶区，左右各超过最终切边少量余量
U：前→后；V：左→右
边：T_F、T_B、T_L、T_R；哪些是自然边/后续修剪边分别注明
输入：侧视拱高/高点、顶视宽度分布和有依据的横向圆扁；先比较控制网母面与边界试面。Q 截面默认用于检验，不默认作为 Loft 输入
约束：背部拱高、侧视高点、顶视最大宽位置；不可为Match移动已确认的主剪影
接缝：左右过渡带按反射需要G2；前端若为零件开缝则不跨缝强求连续
出口：固定相机轮廓/关键点与主截面通过；有效性通过；内部无非预期波浪
回退：检查未受控的体量/纵向边界，重审方法与分区；不靠不断加截面延续错误路线
```

## 1. 完整可执行例：120×70、最高40的双曲率产品壳母形

### 1.1 任务与边界

输入单位为当前文档单位；测试在毫米文档。设计总长120、总宽70、肩线高度10、顶点高度40，底面z=0。四周保留**有意G0硬边**。输出一块双曲率盖、四壁、底面，以及合并后的有效封闭体。

这验证“明确参数→控制网→派生边→侧壁→底面→Join→检查”的完整母形链。它**不是**真实照片重建、薄壁注塑件、鼠标成品或G2过渡示例，不能拿这次通过声称完成这些任务。

### 1.2 分面与曲线来源

| 面块 | 范围与边界 | UV与方法 | 连续性 |
|---|---|---|---|
| P01 | 整块矩形上盖，四边都在z=10 | U沿长、V沿宽；Degree3×4、4×5 CP，双向单跨 | 四周硬转折，目标G0 |
| P02–P05 | P01每条自然边到z=0对应投影边之间 | 上下边方向一致的直纹面 | 与盖/底/邻壁G0 |
| P06 | 四条z=0投影边组成的闭合平面环 | PlanarSrf等价构造 | 与四壁G0 |

侧壁上边**直接提取P01边**，不能重新描画一套“看似一样”的线。脚本P02–P05按实际边顺序编号；不要假定某个边索引永远等于左/右，正式项目需按几何方位重新映射。

### 1.3 上盖控制网怎样决定体量

U有4列，x等分0、40、80、120；V有5列，y等分−35到35。设纵向形状系数 `a=[0,1,1,0]`，横向 `b=[0,1,1,1,0]`：

```text
CP[i,j].z = 10 + A * a[i] * b[j]
A = (40 - 10) / (0.75 * 0.875)
```

两组Bernstein多项式在中点的峰值分别为0.75和0.875，所以**实际曲面中心**为(60,0,40)，四周边为z=10。控制点高度可能超过40，这是正常控制包络；不能拿CP最高点当曲面实际高度。

### 1.4 操作步骤与检查

| 步骤 | 操作/真实API | 本步出口 | 失败先查 |
|---|---|---|---|
| 1 | 创建非有理NurbsSurface，order4×5，CP4×5，设夹持单跨节点 | Degree3×4，Span1×1，曲面有效 | degree/order、点阵索引、节点 |
| 2 | 设置x/y/z点阵，转Brep | 中心z=40，四边z=10 | 把控制点值误当实面值、UV方向 |
| 3 | 每条边DuplicateCurve，副本PlanarProjection至XY | 每对上/下边对应且同方向 | 误选内部等参线、投影平面 |
| 4 | 每对边CreateRuledSurface→Brep | 四个有效侧壁，与上盖共享位置 | 边方向或断开 |
| 5 | 下边JoinCurves闭合，再CreatePlanarBreps | 一个有效底面 | 环不闭合、非共面、多环 |
| 6 | 六面JoinBreps | 一个有效Solid，无裸边/非流形边 | 实际缝隙、重复面、公差 |
| 7 | 校正实体朝外，VolumeMassProperties检查 | 正体积、六面、朝外 | 翻面或自交；不靠放宽公差 |

### 1.5 可直接运行

在Rhino Python3中，`skill_root`为本技能安装目录：

```python
import sys
sys.path.insert(0, str(skill_root / 'scripts'))
from example_closed_shell import build_shell, run_example_tests
result = build_shell(__rhino_doc__, length=120, width=70,
                     height=40, shoulder_height=10)
checks = run_example_tests(__rhino_doc__)
print(checks)
# result['patches']保留6块可编辑母面；result['solid']为合并体。
# 默认仅内存构造，不添加/删除用户文档对象。
```

内存例子用于验证构造链。正式落文档时，还须将每个侧壁使用的上/下边、底面闭合输入环保存到 `lines` 并建立面线映射；P01 直接控制网建面应保留可编辑母面和参数，不编造生成线。请按 [原始线保留协议](16-preserve-construction-curves.md) 执行，不能只 AddBrep 成品就称满足编辑交付。

构面封装可用 `patch_with_lines` 的内存结果与 `publish_patch` 完成显式登记；这个参数化壳体脚本本身仍为内存例子，不是自动落盘器。历史 12 项仅验证母形链。

### 1.6 从例子迁移到真实外壳

用户的侧视高点不居中→改纵向截面或控制网系数；顶视收腰→改各列宽度，但重新测实际最大宽，不能仍声称等于输入CP宽度；需要G2侧边→先修改布局预留过渡带，不能把四壁Join后叫G2；需要等厚→另做偏移/封边与自交检查；需要开孔→在已通过的母面上派生切边。每项更改后重查尺寸与相关邻边。

## 2. 带深侧凹的非对称鼠标壳

完整逐步施工见 [15 构面决策第 5 节](15-surface-led-construction.md)。本例已撤销“五条横截面→顶部 Loft”的默认路线。必须先确定顶部、侧面、凹底和过渡带各自的体量职责；诊断截面不是默认生成线。顶部主母面、凹区和肩部需要独立控制，最终方法按真实约束比较。

## 3. 旋转音箱/瓶体：尽量用物品真实生成关系

1. 判断是否真绕轴对称：多视图截面是否圆、侧后是否有扁平区或把手。仅正面像圆柱不够。
2. 真旋转体先设轴A、上下界Z0/Z1与剖面R(z)，分开定义最大腹部半径、高度、顶/底收束和口部。
3. P01主体由一条干净剖面Revolve，接缝放低敏感侧；剖面必要位置用解析线/弧，避免插值每个像素。顶点极区按设计检查切向与平坦度。
4. P02顶盖、P03底座按装配分件；连续外形尽量从共享剖面/母面派生，别重画不一致的一套圆。
5. 网罩颜色先作材质区，不自动挖凹。确有孔再定义孔径/间距/边余量；先一单元再阵列，曲面映射后核对实际间距。
6. 剪影不对时回到R(z)，不靠外加Blend遮住腹部错误。非旋转部位单独建主面及过渡，不能全件硬套Revolve。

验收：轴、总高、最大直径及其高度、顶底轮廓、接口、反射与接缝位置。仅需外观面时无需虚构内部壁厚。

## 4. 三向管柄/Y分叉：把中心单独当一个问题

1. 建三条轴与分支截面，确定外包络、分支夹角、中心宽度和需保持的通道/连接面。
2. 建P01/P02/P03分支主面，保留到中心以外；先看整件比例，再切除交错中心。
3. 按分支之间的法截面设计P04/P05/P06桥接带。三条带各自平顺不等于中心已完成。
4. 中心剩余区域先绘邻接/切线示意，比较多四边补面或更大网络重构；将不兼容汇聚从关键高光区移开。
5. Patch可以初始化中心体量，但需验边区和截面，必要时切宽边带再重构。禁止“Patch补洞后自动G2”的结论。
6. 检查每条分支端的圆/椭圆截面、中心鼓包、星形反射、角点相容；工程要求再查最薄壁、内通道与自交。

失败回退：中心针尖→扩大中心或重定桥接端截面；带间打架→改邻接/边切线；分支轮廓漂移→锁住解析主面并放宽允许变形区域，而不是把整件控制点都加密。

## 5. 模型是否符合用户意图：任务内验收门

| 阶段 | 应展示/记录 | 不通过怎么办 |
|---|---|---|
| 体块 | 固定相机的轮廓、比例、主高点、负空间 | 调相机/深度假设与体块，暂不做细节 |
| 母面 | 主要截面、曲率走向、可编辑结构 | 调截面或分面，不先补孔 |
| 过渡 | 关键接缝样本、反射、角区；G2证据状态 | 扩带/重排或如实声明限制 |
| 细节 | 用户关键特征逐项对应，位置/尺寸/数量 | 局部修正且回查母形 |
| 工程 | 按合同的厚度/干涉/拔模/交换检查 | 不以外观通过代替工程 |

有图像能力时实际查看固定相机输出，用户要求不读图或没有工具时明确只做数值检查。**不能因为Skill详细就承诺任意Agent、任意参考一定成功**。真正的任务基准还需提供参考、目标和最终模型，逐项评分；本包的程序化壳体只验证可执行构造链。


## 输入线保留

生产构面输入须保存到文档 `lines` 图层，保留与面块的对应关系，不在清理时删除。完整要求与 Sweep2 输入说明见 [16 原始构面线](16-preserve-construction-curves.md)。
