# 参数预算与可迁移配方

## 数值类型先分清

| 类型 | 例子 | 如何采用 |
|---|---|---|
| 输入事实 | 图纸尺寸、材料规格 | 校核单位和版本后作为约束 |
| 项目预算 | 接缝、拟合、角度误差 | 明确定义与目标，再设置工具 |
| 探索起点 | 概念过渡宽度、显示网格 | 试面和指标验证后调整 |
| 教材案例 | Patch刚度、Pipe量规半径 | 保留上下文，不能自动迁移 |
| 工程标准 | 厂商接缝、拔模、缩率 | 需规范来源/版本；没有则未确定 |

## 单位换算与探索设置

0.01mm对应cm单位0.001、m单位0.00001、inch约0.0003937。这是同一物理量的换算，不是所有项目都应取该值。改变单位时明确是否缩放坐标、参考和长度公差；角度无须按长度缩放，曲率按长度倒数换算。

对约100–1000mm普通外观概念，文档绝对公差0.01mm、接缝距离0.01mm、切平面角0.1°可作为**待验证探索预算**，不是制造标准，也不覆盖用户现有设置。模糊图的形状拟合误差往往更大，按参考不确定度设定。

尺度缩放仅适用于相似概念形体。真实壁厚、工艺圆角、间隙和缩率分别由功能/材料/供应链确定，不拿汽车总长与音箱总长的比例推算。

## MatchSrf配方

输入：可调整源面、目标面真实边、主从、连续性及各项容差。

1. 记录原面和邻接边，检查自然/修剪边、对应与角点。
2. 初始差距太大先调体量，避免用匹配硬拉。
3. 按目标选Position/Tangency/Curvature；选择另一端保持要求。
4. Preserve iso可作试验，按形体比较Automatic/目标iso/垂直边策略；不要求所有UV相同。
5. 两侧允许改时才Average；部分长短边匹配可试closest points，并检查覆盖。
6. Refine与手动InsertKnot分别试验，控制新增自由度；复查所有旧边与面内公平性。

教材曾显示Distance0.001 units、Tangency1°、Curvature0.05%，这是旧案例设置，不是当前软件永恒默认，也不是无量纲通用标准。曲率误差仍需明确当前工具定义。

## Pipe切带后桥接

适用：两母面交会，允许切出足够过渡域，不要求最终过渡严格固定半径。

```text
Intersect检查交线 → 必要时Join相关交线段
→ Pipe构造切割量规 → 延伸量规到越过目标边界
→ Split/Trim母面，保留所需两侧
→ A: BlendSrf；或B: 设计截面+Sweep2并设真实面边连续性
→ 验接缝、带宽、内部曲率和角区
```

Join交线不是Join母面，二者都不自动提高连续性。开放量规便于延长；有封盖的切割体也可切面，不能断言Cap使切割不可能。Pipe半径由需要的切割域试验决定，书中宽度2/3只作局部例子，不能保证等宽/固定圆角。

## 微鼓按钮候选

输入：轮廓、拱高、侧壁、目标边缘软硬。直线+半圆轮廓通常G1；需要曲率过渡时可Blend。把盖面横向建成单跨Degree2三排，仅动中排可做微鼓；不是任意降成Degree2就恰好三排，也不保两端G2。需要端部曲率控制时用更多自由度/更合适截面，最终接缝独立验收。

## Patch / Network

Patch的点距为长度量，spans和刚度按数据/尺度试验；Adjust tangency开关取决于是否有可用真实面边与所需切向，不能普遍禁用。旧按钮例U/V spans2、stiffness0.1只说明一个近似鼓面的设置。

Network先检查两族交点、顺序和边连续性输入语义，拟合容差越宽通常更易简洁但偏差可能增大；记录实际输出与验差，不能把0.01/1/10当跨单位的固定档位。

## 网格与输出

先设可接受弦高/角偏差、最小特征与面数预算，再调网格；例如毫米制外观预览可先试弦高0.05mm、角度10°，再放大关键区核验。这是探索值，超小特征、打印或工程交换需重定。

最短边过大可能截断需要的细化；初始四边数也不代替弦高控制。检查接缝一致、锐边法线与长瘦三角；Rhino Weld角度与其他软件按距离合点不同。输出STL等不可靠携带单位的格式需随附单位说明。
