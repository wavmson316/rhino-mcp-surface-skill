# 破面分类与阻断检查

“破面”不是一个唯一原因。先保留失败候选和输入，按证据分类。

| 症状/事实 | 判断与下一步 |
|---|---|
| `None`、空结果、无效 Brep、零面积 | 本步骤失败，禁止登记为成功；查输入、单位、交点、方向和真实 API 返回状态 |
| 意外裸边/不相接 | 明确应闭合的接缝，量测实际缺口并追踪共享边来源；开放外观面本就可能有合法裸边 |
| 自交、折返、极窄退化带 | 检查截面对应、闭合缝、轨道、角点及母面域；扩大重构区域，不以 Join/放宽公差遮盖 |
| 重叠面、闪烁、棋盘纹 | 先隔离重复/共面副本与显示状态；清理只针对本任务明确重复对象，不先缩放孔口改变设计 |
| 几何有效但有意外折痕 | 查横向切平面/曲率与面内起伏；边相同不等于面光顺 |
| 只在显示中有裂缝/锯齿 | 比较实际曲线/接缝测量及不同显示网格；重建显示网格不代表几何已修复 |
| 阵列接界缺口/碎面 | 先测一个单元的扇区边、相位与旋转后邻接，再扩展阵列；不能全阵列后猜补 |

## 每步三道检查

1. **输入**：全部输入有效且未被静默丢弃；曲线来源、方向/闭合缝/排序明确；网络两族交点一致；切割域确实穿过目标；公差有来源。
2. **输出**：只检查本次原生 API 直接返回或本批新增的对象，禁止遍历全场景取第一张面当结果。检查返回状态、有效性、面积、面数、重复和非流形；仅当合同要求时查水密/实体方向。
3. **形体/邻接**：检查关键轮廓、站位间体量、局部截面、接缝覆盖与对应。`IsValid`、正体积和水密均不能单独证明无自交或形体正确。

可先用 `quality_gate.check_candidates` 运行结构阻断；其 `unverified` 明确列出未检查的自交、参考相似度、公平性和 G 级。单张开放主面可以通过结构检查，但不能因此认为整件应为实体的交付已通过。

```python
from quality_gate import check_candidates
report = check_candidates(result['breps'], require_solid=False)
if not report['passed']:
    raise ValueError(report['errors'])
# 按当前任务完成形体/接缝检查后再 publish_patch。
```

几何自交需要对应版本工具和局部/全域检查；采样法可能漏检，不假报全域无自交。禁止 `JoinEdge`、全局放宽公差或删坏面后直接称完成。保留失败原因，回退最后通过的母面版本。
